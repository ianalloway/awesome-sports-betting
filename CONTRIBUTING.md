# Contributing to Awesome Sports Betting

Thank you for your interest in contributing! This list aims to be the most useful collection of sports betting resources on the internet, and your help makes that possible.

## Guidelines

### What qualifies for this list?

A resource is "awesome" if it meets one or more of these criteria:

- **Actively maintained** -- The project or resource is kept up to date and responsive to issues.
- **Genuinely useful** -- It solves a real problem for sports bettors, handicappers, or sports analysts.
- **High quality** -- Well-documented, reliable, and respected within the community.
- **Free or has a free tier** -- Preference is given to open-source and free resources, though paid tools that are clearly best-in-class are welcome.

### What does NOT belong?

- Tipster services or pick-selling sites.
- Affiliate-heavy "review" sites with no real content.
- Abandoned projects with no updates in 2+ years (unless they are seminal/foundational).
- Self-promotion without genuine value to the community.

## How to Contribute

### Adding a New Resource

1. **Fork** this repository.
2. **Create a new branch** from `main`:
   ```bash
   git checkout -b add-resource-name
   ```
3. **Add your resource** to the appropriate section in `README.md`.
4. Use the following format:
   ```markdown
   - [Resource Name](https://url.com/) - Brief, objective description ending with a period.
   ```
5. **Keep descriptions concise** -- One sentence, starting with a capital letter, ending with a period.
6. **Place entries alphabetically** within their section, or at the end if the section has a logical ordering.
7. **Commit your changes**:
   ```bash
   git commit -m "Add Resource Name to Section Name"
   ```
8. **Push** to your fork and open a **Pull Request**.

### Suggesting a New Section

If you think a new section is needed, open an issue first to discuss it. Include:

- The proposed section name.
- At least 3 resources that would belong in it.
- Why it deserves its own section rather than fitting into an existing one.

### Reporting Broken Links

If you find a broken link, please open an issue with:

- The resource name and current URL.
- Whether the resource has moved (provide new URL if known) or is completely gone.

## Pull Request Requirements

- [ ] Each PR should add or modify **one resource at a time** (unless doing a bulk cleanup).
- [ ] The resource URL must be working and point to the correct destination.
- [ ] The description must be **objective and factual**, not promotional.
- [ ] No duplicate entries -- search the list before adding.
- [ ] Follow the existing formatting conventions exactly.

## Code of Conduct

Be respectful and constructive. This is a community resource meant to help everyone involved in sports analytics and betting. Disagreements about resource inclusion should be handled through polite discussion in issues and pull requests.
